O CalculaNota é uma aplicação web simples que ajuda estudantes a descobrir quanto precisam tirar em uma próxima avaliação para alcançar a média desejada.
A ideia é resolver uma dúvida muito comum entre estudantes de forma rápida e prática, sem precisar fazer cálculos manualmente.

O projeto foi desenvolvido como atividade acadêmica, com o objetivo de praticar conceitos de desenvolvimento Web utilizando tecnologias executadas diretamente no navegador, sem a necessidade de um back-end próprio.
